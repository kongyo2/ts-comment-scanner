# Contributing

[日本語](#日本語) | [English](#english)

## 日本語

### メンテナ

ts-comment-scanner のメンテナは kongyo2([@kongyo2](https://github.com/kongyo2))です。プロジェクトの方針と、どの変更をマージするかは、メンテナが最終的に判断します。コントリビューションは歓迎しますが、プロジェクトの目的やコーディング規約に合わない提案は採用しないことがあります。

### Issue と Pull Request

バグの報告や機能の提案は Issue にお願いします。大きな変更は、Pull Request を作る前に Issue で相談してください。

Pull Request では CI が通るようにしてください。動作を変えるときは、テストとドキュメントも更新してください。

## English

### Maintainers

ts-comment-scanner is maintained by kongyo2 ([@kongyo2](https://github.com/kongyo2)), who has the final say on the direction of the project and on which changes are merged. All contributions are welcome, but please understand that a suggestion may not be accepted if it doesn't align with the project's goals or coding standards.

### Issues and pull requests

Please report bugs and suggest features in issues. For a large change, open an issue to discuss it before opening a pull request.

Make sure CI passes on your pull request. If you change behavior, update the tests and documentation too.
